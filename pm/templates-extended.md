# Message Templates (Extended & Rare) — KIM Project Manager

Read this on demand when formatting non-daily reports or escalation templates.
Daily rhythm templates remain canonical in `AGENTS.md`.

## At Risk Escalation (WhatsApp)

Post when a blocker cannot be self-resolved after 3 days or requires immediate principal intervention:

```
🚨 *At Risk*
{task} — @owner — {alasan}
Butuh keputusan: @Faiz
```

## 30-Day Retrospective Review (WhatsApp)

Post at month-end or on 30-day cadence using the 18:00 report structure plus:

```
📉 *Kepatuhan Update*
• {owner}: {rate}% update compliance ({on_time}/{total_days})

💡 *Rekomendasi*
• {recommendation}
```
